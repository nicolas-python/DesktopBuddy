## Technologien
Blender:
    - Kostenlose 3D-Software
    - Erstellung und Bearbeitung von 3D-Modellen
    - Erstellung von Animationen und Materialien
    - Export der Modelle für Godot

Godot Engine:
    - Game Engine zur Entwicklung interaktiver Anwendungen
    - Darstellung des 3D-Charakters
    - Verwaltung von Szenen und Animationen
    - Fenstersteuerung und Benutzerinteraktionen
    - Export als eigenständige Windows-Anwendung

GDScript:
    - Programmiersprache für Godot
    - Ähnelt in der Schreibweise Python
    - Steuert Bewegungen, Funktionen und Reaktionen


## Godot Engine
ColorRect : in Rechteck, dessen Farbe und Größe man selbst bestimmen kan

project_folder = Path(__file__).parent
    - Path(...)	Macht aus einem Pfad ein Path-Objekt
    - __file__	Speicherort der aktuellen Python-Datei
    - .parent	Übergeordneter Ordner



DesktopBuddy.exe :

extends Sprite2D		#Verwendet paperclip_buddy.png als Grundlage für das Script

func _input(input_event: InputEvent) -> void:			#-> was die funktion zurück gibt void = keine rückgabe
	if input_event is InputEventMouseButton:
		if input_event.button_index == MOUSE_BUTTON_LEFT and input_event.pressed:
			if get_rect().has_point(to_local(input_event.position)):
				DisplayServer.window_start_drag()		#Übergibt das Verschieben des Fensters an Windows

func _ready() -> void:
	get_window().mode = Window.MODE_WINDOWED
	get_window().min_size = Vector2i(256, 256)  #Kleinste erlaubte Fenstergröße
	get_window().size = Vector2i(256, 256)      #Fenstergröße auf 20 × 20 Pixel
	position = Vector2(128, 128)
